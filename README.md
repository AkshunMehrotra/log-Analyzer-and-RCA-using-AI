# 🔎 AI Log Analyzer & RCA Tool

## AI-Powered Contact Center Log Analysis & Root Cause Analysis

The **AI Log Analyzer & RCA Tool** is an AI-powered application designed to analyze contact center system logs, detect errors and incidents, identify probable root causes, and generate actionable recommendations.

The system combines a **FastAPI backend**, **Streamlit dashboard**, **rule-based log analysis**, and **LLM-powered executive reporting** to provide an end-to-end log monitoring and Root Cause Analysis solution.

---

## 🚀 Key Features

- 📁 Upload `.log`, `.txt`, and `.csv` files
- 🔍 Automatic log parsing and classification
- 📊 Log statistics and system health calculation
- 🚨 Error and warning detection
- 🤖 Automated incident detection
- 🧠 AI-powered Root Cause Analysis
- 💡 Recommended corrective and preventive actions
- 📈 Interactive dashboard visualizations
- 🥧 Log distribution and incident severity charts
- 📋 Detected incident table
- 🔎 Detailed RCA for individual incidents
- 📑 AI-generated Executive Health Report
- 📄 Uploaded log preview
- 🔐 File validation and unsupported-file rejection
- ⚡ REST API support through FastAPI
- 📚 Automatic Swagger/OpenAPI documentation
